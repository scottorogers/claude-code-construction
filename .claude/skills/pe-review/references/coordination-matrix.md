# Coordination Matrix

When a query touches ANY of these interfaces, actively check both scopes for conflicts. Numbered rows match `reference/pe_expertise/pe_behavior.md` §5.

| Interface | Scope A | Scope B | What Fails |
|---|---|---|---|
| Slab rebates | RC frame | Flooring | Depth doesn't account for full build-up (membrane + screed + tile) |
| Underslab services | Groundworks / slab | Public health / electrical / comms | Drainage and ducts not coordinated before slab pour |
| Cast-in items | RC frame | Steel / M&E | Holding-down bolts or sleeves missed before pour = drilled fixings at far higher cost |
| Basement waterproofing | RC frame | Tanking | Membrane termination not detailed at ground level; BS 8102 grade not stated |
| Masonry support | Brickwork | Steel | Support angles misaligned with structure; deflection limits not met |
| Cavity drainage | Brickwork | DPCs / trays | Cavity trays not continuous; weep vents blocked |
| Steel fire protection vs M&E | Fire protection | All M&E | Fixings through intumescent/board without repair protocol |
| Airtightness at windows | Envelope membranes | Windows / CW | Discontinuous at frame = main air leakage location |
| Slab-edge fire-stopping | Curtain wall / cladding | Fire-stopping | Slab edge gap not fire-stopped / cavity-barriered at each floor |
| Fire-rated partition penetrations | Drylining | All M&E and comms | Services through fire-rated wall without a tested fire-stopping system |
| Pattressing | Drylining / carpentry | Sanitaryware, AV, FF&E | Not installed before board closure |
| Ceiling coordination | Suspended ceilings | All M&E | Sprinklers, grilles, lights, detectors, speakers, WAPs not on grid |
| Mech-elec match | Mechanical | Electrical | Supply rating / phase / isolator mismatch between schedules |
| Ironmongery + access control | Doors / ironmongery | Security | Electric locks not coordinated; power/ELV not to frame; fail-safe vs fail-secure not agreed |
| Fire alarm integration | Fire alarm | Mechanical / lifts / sprinklers / access control | Cause-and-effect gaps — AHU shutdown, dampers, lift homing, flow switches, door release |
| Incoming services | Utilities / civils | Building M&E | Duct/pipe size or position mismatch at building entry |
| Equipment services | Equipment / catering | All M&E | Requirements not provided; first fix mislocated |
| Furniture power/data | FF&E | Electrical / comms | Floor box and outlet locations don't match furniture layout |
| Roof penetrations | Roofing | All M&E | Not flashed; upstands inadequate; no walkways |
| Slab flatness vs flooring | RC frame / screed | Flooring | Flatness tolerance insufficient for specified flooring |
| Public health vs arch fixtures | Public health | Architectural | Sanitaryware counts/locations mismatch |
| Catering + suppression | Catering | Fire suppression | Canopy without wet chemical suppression where specified |
| Lifts + fire systems | Lifts | Fire alarm | Lift fire control not integrated; no pit drainage; no motor room ventilation |
| Fire-rated walls + doors | Fire strategy / Arch | Doors / ironmongery | Fire-rated wall with non-rated door, or fire door missing self-closer/seals |
| Containment fill + segregation | Electrical | Comms / security | Tray/basket sized for power only; no power/data segregation; no spare capacity |
| Comms room environment | Comms | Mechanical / electrical | No dedicated cooling, no UPS/generator supply, no earth bar, room too small |
| Roofing + PV | Roofing | Electrical / structural | Penetration flashing, structural loading, cable routes, warranty |
| Warranty across sections | Roofing | Flashings / sealants | Single-manufacturer system requirement — mixed products void warranty |
| Inverter drives + plant room cooling | Mechanical plant | Mechanical | Drive heat gain not included in plant room cooling |
| Controls cabling | Electrical | BMS controls | Who installs controls cabling; segregation from power cabling |
