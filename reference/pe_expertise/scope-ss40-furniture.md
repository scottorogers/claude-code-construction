# Scope File: Ss_40 — Fitted Furniture, Blinds and Loose FF&E

**Load when:** Query references fitted furniture, workstations, desking, blinds and window treatments, loose furniture, reception desks, or Uniclass `Ss_40_15` / `Ss_40_45` FF&E groups (CAWS `N` sections on legacy specs).

**Red flags and coordination matrix are in pe_behavior.md (always loaded).**

---

## Cross-Reference Triggers

- Furniture layout — desk positions, power/data positions, floor boxes, cable management.
- Blind schedule — manual or motorised; supplies at window heads.
- Client-supplied vs contractor-supplied split (CAT A / CAT B on office fit-outs).

---

## Absence Detection Checklist

- [ ] Desk and floor box positions match the furniture layout revision used by electrical and comms. (Matrix #18)
- [ ] Motorised blind supplies and control cabling in before closure.
- [ ] CAT A / CAT B scope boundary written down (who provides floor boxes, desk power modules, patch leads).
- [ ] Reception desk services and access control/door entry interfaces.

---

## Sequencing Context

```
Furniture layout frozen → floor box / grid positions set → cabling → furniture delivery after clean
```

## Coordination Overlaps

- **With Electrical / Comms:** floor boxes, desk power and data. (Matrix #18)
