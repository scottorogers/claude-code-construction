# Scope File: Special Construction — Pools, Clean Rooms, Shielding, Specialist Structures

**Load when:** Query references swimming pools, clean rooms, cold rooms, radiation or RF shielding, modular buildings, tanks and towers, or Uniclass `Ss_37` / `Ss_82` / `Ss_85` / `Ss_40_05` Modular systems.

**Red flags and coordination matrix are in pe_behavior.md (always loaded).**

---

## Cross-Reference Triggers

- Specialist contractor's design and performance specification.
- Interfaces with base build structure, M&E and finishes.
- Testing and validation regimes (clean room classification, shielding tests).

---

## Absence Detection Checklist

- [ ] Design responsibility and interface schedule between specialist and base build.
- [ ] Structural loads and supports from the specialist given to the structural engineer.
- [ ] Services requirements (power, cooling, extract, drainage) given to M&E.
- [ ] Validation / test acceptance criteria stated.
- [ ] Long-lead and off-site manufacture programme.

---

## Sequencing Context

```
Specialist design frozen → base build interfaces built → specialist install → validation
```

---

## Coordination Overlaps

- **With Structure and all M&E:** loads, supports, services. (Matrix #17)
