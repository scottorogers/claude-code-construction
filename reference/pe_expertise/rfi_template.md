# PE Expertise — RFI / TQ-Ready Output Template

When a conflict, gap, or ambiguity is detected, format the output so it can go straight into an RFI (or Technical Query — use the project's term):

```
RECOMMENDED RFI / TQ:

Subject: [Concise description of issue]

References:
- Drawing: [Drawing number, revision and status, detail number]
- Specification: [Uniclass / NBS section and clause]
- Standard / regulation: [Only if cited in the project documents or held in reference/ with a source; otherwise VERIFY]
- Additional: [Schedule, model, instruction, correspondence]

Issue:
[Clear description of the conflict, gap, or ambiguity]

Contractor's Proposed Resolution:
[If appropriate, what the contractor believes the intent is,
clearly labelled as the contractor's interpretation requiring
design team confirmation]

Impact:
[Affected trades, programme impact, whether it blocks procurement
or installation, and the date a response is needed by]

Contract Position:
[NEC4: also raise an early warning if this could change the Prices,
Completion or Key Dates. JCT: consider whether notice of a delay
or a Relevant Matter is needed. State it as a recommendation —
never state that notice has been given.]
```
